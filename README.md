# Mindful Companion

Մինիմալիստական մոտիվացիոն հավելված (PWA)՝ օրական մեկ քվոթ + էմոցիոնալ check-in։ Առանց սերվերի և build-ի, միայն HTML/CSS/JS։

**Բացել հավելվածը.** https://renekarapetyan.github.io/mindful-companion/

Հեռախոսում բացիր հղումը և ընտրիր «Add to Home Screen» / «Ավելացնել գլխավոր էկրանին». հավելվածը կաշխատի նաև առանց ինտերնետի։

## Հնարավորություններ

- Եռալեզու ինտերֆեյս (hy / ru / en), անուն կամ նիկնեյմ, մի քանի օգտատեր նույն սարքում։
- Օրական քվոթ՝ հաջորդականությամբ։
- Check-in. 7 տրամադրության ընտանիք (Mood Meter) → ~30 կոնկրետ էմոցիա՝ նկարագրությամբ → կոնտեքստի պիտակներ։
- Պատասխան ըստ տրամադրության, 1 րոպեանոց շնչառական պրակտիկա։
- «Կիսվիր օրով». ուղղորդող և ճշգրտող հարցեր, երեկոյան ամփոփում։
- «Մտքեր քեզ համար». քվոթեր ըստ տրամադրության, ♥ պահպանում, կիսվել որպես նկար։
- «Իմ օրերը». շաբաթվա streak, ամսվա օրացույց, տրամադրությունների բաշխում, եզրակացություններ, JSON/CSV արտահանում, օրական հիշեցում (.ics)։

## Գաղտնիություն

Բոլոր տվյալները պահվում են **միայն օգտատիրոջ բրաուզերում** (`localStorage`)։ Սերվեր, հաշիվ կամ անալիտիկա չկա. ոչինչ չի ուղարկվում։ Եթե բրաուզերի տվյալները ջնջվեն, գրառումներն էլ կջնջվեն, ուստի պարբերաբար արտահանիր JSON-ը։ Պրոֆիլները գաղտնաբառով պաշտպանված չեն. նույն սարքի օգտատերերը կարող են տեսնել միմյանց գրառումները։

Հավելվածը փոխարինում չէ հոգեբանի կամ բժշկի օգնությանը։

## Գործարկում

Պարզ տարբերակ՝ կրկնակի սեղմիր `index.html`-ի վրա։

Լիարժեք (offline + «Add to Home Screen» հեռախոսում)՝ պետք է http սերվեր.

```bash
py -m http.server 5173
```

Ապա բացիր http://localhost:5173։

## «Կիսվիր օրով» սեսիա

- Մեկ սեսիա = առավելագույնը 3 հարց (1 ուղղորդող + 2 ճշգրտող)։
- Դրանից հետո հավելվածը ցույց է տալիս ամփոփում. պատասխանները, եզրահանգումը և «եթե-ապա» առաջարկը։
- Տրամադրությունը փոխելիս կարելի է նոր սեսիա սկսել։ Մանրամասները՝ `docs/psychology-methods.md`։

## Քվոթերի հերթականությունը

- Առաջին օրը՝ ID 1։ Ամեն **նոր օր**, երբ օգտատերը բացում է հավելվածը, ցուցադրվում է հաջորդը (`ID + 1`)։
- Նույն օրը քանի անգամ էլ բացվի, քվոթը չի փոխվում։
- Եթե օգտատերը մի քանի օր չի բացել, քվոթեր բաց չեն թողնվում. նա շարունակում է իր հաջորդականությունից։
- Բազայի վերջում հերթականությունը սկսվում է նորից։

## Նոր քվոթ ավելացնել

`data/quotes.js`-ում զանգվածի վերջում ավելացրու օբյեկտ հաջորդ `id`-ով.

```js
{
  "id": 11,
  "author": "Seneca",
  "book": { "hy": "…", "ru": "…", "en": "…" },
  "text": { "hy": "…", "ru": "…", "en": "…" }
}
```

Հրապարակելուց հետո `sw.js`-ում փոխիր `CACHE`-ը (օր.՝ `mc-v2`), որ օգտատերերը ստանան նոր տարբերակը։

## Տվյալներ

Ամեն ինչ պահվում է միայն օգտատիրոջ սարքում (`localStorage`)՝ լեզուն, քվոթի ինդեքսը և օրվա check-in-ը։ Սերվերին ոչինչ չի ուղարկվում։
